# WebApplicationEntrypoint/appsettings.Development.json

## Propósito
Sobrescreve configurações para ambiente de desenvolvimento.

## Código anotado

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft": "Warning",
      "Microsoft.Hosting.Lifetime": "Information"
    }
  }
}
```

### Anotações técnicas
- **Config por ambiente**: permite ajustes sem impactar produção.
